🚀 HOW TO USE
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Setup Backend:
   cd portfolio/backend
   cp .env.example .env
   # Edit .env with your Groq API key

2. Setup Frontend (Optional):
   cd portfolio/frontend
   cp .env.example .env
   # Leave as-is for localhost, or set VITE_API_URL for production

3. Run Backend:
   cd portfolio/backend
   python main.py

4. Run Frontend (new terminal):
   cd portfolio/frontend
   npm run dev

5. Open: http://localhost:5174
